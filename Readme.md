# Task 6: CSS - Laundry Mart Login Page using Flexbox

A split-screen login page built with plain HTML and CSS (no Bootstrap).

## Files

- `index.html` - page structure
- `index.css` - all styling, linked from the HTML
- `laundry.png` - laundry illustration shown on the left
- `Readme.md` - this file

## What was done

- **Container:** height is `100vh`; content is centred using Flexbox (`display: flex`, `justify-content`, `align-items`), not margin or padding.
- **Left section:** a laundry image, centred with Flexbox.
- **Form section:** a login form inside the right section, laid out with Flexbox.
- **Heading:** friendly greeting "Hi Again!" with a short welcome line.
- **Inputs:** email and password fields with `type` and `placeholder` set, styled with padding, border, radius and a focus effect.
- **Login button:** labelled "Login", styled with a blue gradient and hover effect.

## How to run

Keep `index.html`, `index.css` and `laundry.png` in the same folder and open `index.html` in a browser.
